# Taimanin Franchise — Research Reference

A structured reference on the *Taimanin* franchise (Lilith / Black Lilith, 2005–),
compiled as background for this project's multiverse simulation. It covers every
branch of the franchise — the adult visual novels, the OVAs, and the mainline and
mobile games — as sources on an equal footing.

**Status:** research draft for the creator's review, November 2026.
**How it will be used:** version 0.1 of the game is planned as an *original*
demon-hunting ninja world. These documents are a genre reference for that design,
not a specification to reproduce. Document 12 is written with that in mind.

## Conventions

**Names** are in Western order (given name first) in prose.

**Continuity tags.** The franchise is an explicit multiverse; facts often hold in
one branch only.

| Tag | Continuity |
|---|---|
| `[VN]` | The original visual-novel canon (*Asagi 1–3*, *Murasaki*, *Yukikaze 1–2*, *Kurenai* and side stories) |
| `[ZERO]` | *Taimanin Asagi ZERO* — a rebooted first game |
| `[TABA]` | *Taimanin Asagi Battle Arena* — browser card game |
| `[RPGX]` | *Taimanin RPG / RPGX / RPG Extasy* — turn-based gacha RPG |
| `[AT]` | *Action Taimanin* — all-ages action game |
| `[GOGO]` | *Taimanin GOGO!* — comedy roguelike |
| `[SQ]` | *Taimanin Squad* — all-ages squad RPG |

An untagged statement holds across continuities as far as the sources show.

**Confidence.** Each document closes with a *Conflicts and uncertainty* section.
In the text, "the wiki's" or "unofficial" marks fan synthesis; "possibly" and
"said to" mark things the sources themselves leave open. Document 12 uses explicit
`[official]` / `[snippet]` / `[lore]` / `[proposal]` markers.

## Sources and method

| Source | Used for | Access |
|---|---|---|
| **Taimanin Wiki** (taimanin.fandom.com) | The bulk of the lore: 2,581 articles read from a full text download through the site's public API | Reachable through the API only (ordinary page views are blocked by a bot check) |
| **Wikipedia**, English and Japanese | Release dates, staff, publication history | Reachable |
| **VNDB**, **MyAnimeList** | Cross-checks on titles, dates and adaptations | Reachable |
| **Steam store** | Official descriptions of the three online games | Reachable |
| Web search excerpts | Gameplay systems of the online games | Excerpts only — the pages themselves were blocked |

Method: download the wiki text, read by category (lore, locations, factions,
species, powers, items, technology, characters), cross-check dates against
Wikipedia and VNDB, and write summaries in our own words. No text is copied at
length.

**Caveats about the main source.** The fan wiki is itself a synthesis written by
enthusiasts, largely from Japanese-language games. It mixes stated canon with
editorial inference (its taxonomies of arts and species and its power-tier list
are its own), its English is uneven, and some entries are flagged by its own
editors as speculative. Where that matters the documents say so.

## Known gaps

- **No numeric game data** — stat tables, damage formulas, drop and gacha rates —
  for any title.
- The five-attribute advantage chart of the turn-based RPG is unconfirmed.
- Enemy rosters of the online games are only partly recorded.
- Light novels, manga and drama CDs are covered through the wiki's summaries, not
  read directly.
- Roughly 1,250 minor characters (mostly gacha units) are not profiled.

## Content note

Much of the franchise is adult fiction with dark themes: capture, coercion,
forced modification and mind control are central plot devices. These documents
record that material factually, by function, and without graphic description,
so that the reference stays usable as a design document. Characters who are
students in a given continuity are described in non-sexual terms throughout.
